# Calculateur de notes

Programme Python qui calcule la moyenne d'un etudiant.

## Fonctionnalites

- Demande le nom de l'etudiant.
- Permet de choisir le nombre de notes.
- Verifie que chaque note est un nombre entre 0 et 20.
- Calcule la moyenne et affiche la decision.
- Enregistre le rapport dans `resultats.txt`.

## Utilisation

Lancer le programme avec Python 3 :

```bash
python calculateur_notes.py
